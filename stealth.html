Development Intelligence Platform

Development intelligence and analytics for R&D leaders

An early-stage startup building a development-intelligence platform. It unifies data from Git, project management and GenAI tools to show R&D leaders how their teams build software, and what it costs.

I was the only designer, working with three engineers and early customers. I defined and designed new features based on what customers needed to see, and redesigned a product that until then had been designed by the engineers themselves.

Competitive analysis

I analyzed five competitors in depth; three are shown here with their main features, strengths and limitations. It’s a snapshot of the research that guided the design decisions.

  • Competitor 1

    Key features
    Cycle time metrics, Automation bot, Slack integration
    Strength
    Intuitive, easy-to-use interface
    Limitation
    No cost or ROI insights. Lacks financial reporting.

  • Competitor 2

    Key features
    Code-level reporting, PR and commit analytics, Benchmarking
    Strength
    Detailed insights into code
    Limitation
    Limited team performance breakdowns. Less focused on team leaders.

  • Competitor 3

    Key features
    Engineering dashboards, Correlates DevOps data, Review workflow metrics
    Strength
    Comprehensive set of reports
    Limitation
    No deep dive into GenAI impact. Focuses on DevOps practices.

Insights that shaped the design

  • Insight 01

    Most tools don’t talk money

    Why: R&D leaders have to justify budget to C-level, and none of the competitors showed cost or ROI.

    Decision: financial indicators on every chart.

    • Quarterly savings comparisons
    • Tooltips translating % to $
    • Direct links to Jira cost items

    Shown in: Jira Spend

  • Insight 02

    There’s data, but no depth

    Why: managers need to find bottlenecks and see team and individual productivity, but competitors stopped at high-level reports.

    Decision: drill-down built into every widget.

    • Navigation from group → team → individual
    • Filtering by repo, quarter or GenAI tool
    • Quick access to team-specific insights

    Shown in: Activity and Developer Profile

  • Insight 03

    GenAI is present but not measured

    Why: teams were adopting GenAI tools, but no competitor measured their impact on productivity or quality.

    Decision: a dedicated GenAI impact dashboard.

    • KPIs comparing AI vs. non-AI contributions
    • Time saved per pull request
    • Usage trends by group and quarter

    Shown in: Activity (POC group = teams using GenAI tools)

The platform

Five screens, from cost down to a single developer

Figures shown are sample data.

01 · Jira Spend

Engineering effort translated into dollars, by issue type and repository, so leaders can see what development actually costs.

02 · Activity

Teams using GenAI tools (the POC group) compared with the rest, across groups, teams and repositories.

03 · Developer Profile

The deepest level of the drill-down: each developer’s contributions, review activity and trends.

04 · Integrations

Connecting the tools the data comes from: project management, Git and CI/CD.

05 · Connecting GitHub

A guided setup for each integration, with OAuth and personal access token options.
